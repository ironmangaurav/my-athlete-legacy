# Gaurav Yadav | My Athlete Legacy

Buildless eight-page athlete website, prepared for free GitHub Pages hosting.

## Publish
Use the repository root on the main branch for GitHub Pages (Settings → Pages → Deploy from a branch). All asset paths are relative, supporting both account and project Pages URLs. No dependencies, paid services or custom domain required.

## Evidence
